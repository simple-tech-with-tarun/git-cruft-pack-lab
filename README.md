# Git Cruft Pack Lab

A practical Git laboratory for understanding object storage,
unreachable objects, garbage collection, and cruft packs.

## Objectives

- Understand Git loose objects and packfiles.
- Explore unreachable and dangling objects.
- Understand Git garbage collection.
- Experiment with cruft packs and expiration metadata.
- Investigate object recovery and pruning.

## Environment

- Git 2.56.0
- Windows
- PowerShell
